O conceito

O que é GitFlow?

GitFlow é um modelo de branches que ajuda a gerenciar o desenvolvimento de software em equipes.

O GitFlow define um conjunto de regras para criar e gerenciar branches, facilitando o desenvolvimento paralelo e a integração de novas funcionalidades.

Pense em caminhos.

Uma branch é uma linha de desenvolvimento. Ela permite trabalhar em uma mudança e depois integrá-la ao restante do projeto.

As branches

Um papel para cada caminho.

Duas branches permanentes.
Três tipos de apoio.

main permanente

Guarda o código pronto para produção e o histórico das versões publicadas.

develop permanente

Reúne as mudanças que farão parte da próxima versão do software.

feature/*

Sai de develop para uma nova funcionalidade e volta para ela ao terminar.

release/*

Sai de develop para preparar uma versão. Seus ajustes chegam a main e develop.

hotfix/*

Sai de main para uma correção urgente, depois integrada a main e develop.

Neste guia, usamos main. No artigo original, essa branch se chama master.

Na prática

Sua primeira feature começa aqui.

Em um repositório que já tenha a branch develop, crie um caminho para a sua nova funcionalidade.

O exemplo usa comandos nativos do Git. Você não precisa instalar uma extensão de GitFlow.

terminal · exemplo 
# Vá para a branch de desenvolvimento
$ git switch develop

# Crie e acesse a sua nova branch
$ git switch -c feature/minha-ideia
Agora, suas mudanças têm um lugar próprio.
